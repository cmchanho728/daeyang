# 제품 스펙 미확정 항목 체크리스트

`npm run build` 시 zod 검증(`src/data/products/validate.ts`)이 published 카테고리에서 찾아낸 항목입니다.
값이 확정되면 해당 데이터 파일(`src/data/products/<category>.ts`)의 `specs`를 채우고, 이 목록에서 체크하세요.
(공개되지 않은 `etc-gasket`은 아직 대상에서 제외했습니다.)

생성 시점 기준 총 **52건** (placeholder "확인 필요" 42건 + 빈 값 10건).
※ 무게 필드가 숫자 없이 "kg"만 있던 10건은 화면에 "문의"로 표시하도록 바꿨습니다. 값이 빈 문자열이 아니라 `validate.ts`가 자동으로 잡아내지 못해 아래에 수동으로 추가했습니다 (총 **62건**).
